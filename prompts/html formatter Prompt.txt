## HTML Mathematical Expression Syntax Checklist
The Problem: HTML treats < and > as reserved characters for tags, causing parsing errors in mathematical expressions.
### Quick Fix Rules:
Replace these symbols in math expressions:
< -> \lt
> -> \gt
<= -> \leq
>= -> \geq

### Check These Common Patterns:

- WRONG: \(\mathrm{2<d<=5}\)
- CORRECT: \(\mathrm{2\lt d<=5}\)

- WRONG: \(\mathrm{d>15}\)
- CORRECT: \(\mathrm{d\gt 15}\)

- WRONG: \(\mathrm{0<n<=1}\)
- CORRECT: \(\mathrm{0\lt n<=1}\)
